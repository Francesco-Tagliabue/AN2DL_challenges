# Artificial Neural Networks and Deep Learning challenges (A.Y. 2025/2026)

Competitions for the "Artificial Neural Networks and Deep Learning" (AN2DL) course at Politecnico di Milano, Academic Year 2025/2026.

## First challenge

**Task:** classification of a collection of multivariate time series, each consisting of 180 time steps and containing measurements from several input channels.


## Second challenge

**Task:** classification of a collection of histological images, originating from low-magnification human tissue WSI, into one of four possible invasive breast cancer subtypes.
